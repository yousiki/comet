# Embedded fonts

The Geist faces are the app and code fonts already shipped by Zeron.

The Terminal uses the complete, unmodified Regular, Bold, Italic, and Bold
Italic faces from Maple Mono v7.9's `MapleMono-NF-CN-unhinted.zip`. Each face
retains the upstream CJK and Nerd Font glyph set; no subsetting is applied.

- Source: https://github.com/subframe7536/maple-font/releases/tag/v7.9
- Archive SHA-256: `ab88522932cf4015dffeaef6dedc59a22a5fefecdcc6e583d9fcd997da5b7cac`
- Family: `Maple Mono NF CN`
- License: SIL Open Font License 1.1; see `MapleMono-OFL.txt`
- Nerd Font glyph set: v3.4.0; see `NerdFonts-LICENSE.txt` and
  `NerdFonts-LICENSE-AUDIT.md`
